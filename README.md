# AI Incident Response Sprint — Track 1

This repository contains our work for **Track 1 (T1)** of the **AI Incident Response Sprint, September 11–13, 2026**.

The project explores approaches to **monitoring potentially risky behavior in AI agents from observable interaction trajectories**, with an initial focus on constructing behavioral risk scores and monitoring how these scores evolve over time.

The repository contains preliminary implementations, experiments, figures, and the accompanying sprint report.

> **Status:** This is an ongoing and preliminary project developed during the sprint. The repository primarily documents our current progress; methods, experiments, and conclusions may be revised as the work develops.
